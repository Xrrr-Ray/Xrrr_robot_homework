# 1. 语音模型是如何把“声音”转成“文本”的？

**回答：**
 语音模型的核心流程一般分为 4 步：

1. **声学特征提取（Acoustic Feature Extraction）**
    常用方法如 MFCC、Log-Mel 频谱，将连续的原始音频信号变成可用于计算的特征矩阵。
2. **声学模型（Acoustic Model）**
    由深度神经网络（如 Transformer、Conformer）组成，负责把声学特征映射到“音素概率分布”。
3. **语言模型（Language Model）**
    在音素序列基础上结合语言上下文，提升识别准确率。
4. **解码器（Decoder）**
    使用 CTC、RNN-T 或 Seq2Seq 等方法，将模型输出转换成最终的文本。

例如：Whisper 使用 **Encoder–Decoder Transformer** 结构，将 Mel 频谱编码再解码为文本。

# 2. 大模型是如何实现实时语音对话的？

**回答：**
 实时语音对话依赖以下关键技术：

- **Streaming/Chunk 分块推理**
   把音频切成很小的片段（几十毫秒）实时处理，而不是等待整段音频结束。
- **低延迟模型结构**
   常用 Conformer、RNN-T 或流式 Transformer，保证刚输入音频就能开始输出。
- **端点检测（VAD）**
   判断用户是否在说话，避免响应过早或过晚。
- **轻量级 TTS 快速合成**
   如 FastSpeech2 + HiFi-GAN，可在毫秒级生成自然语音的语音回复。

流程示意：

```
语音输入 → VAD → 流式ASR → 文本 → 大模型响应 → TTS → 语音输出
```

# 3. 语音模型怎么区分相似的发音，比如 *s* 和 *th*？

**回答：**
 语音模型通过以下方法区分细微音素差异：

1. **高分辨率声学特征（如高维 Mel 频谱）**
    *s* 和 *th* 的频谱分布不同，例如 *s* 的高频能量更强。
2. **大规模训练数据**
    包含大量不同口音、性别、情绪的数据，帮助模型学习到持续稳定的音素模式。
3. **音素级别对齐（forced alignment）**
    训练过程中使用 CTC 或 RNN-T 让模型精确学习每一帧对应的音素。
4. **注意力机制（Attention）**
    Transformer 能把关键帧（例如摩擦音起始和结束）放更高权重，从而区分相似音。

因此，模型可以区分：

- **s**：典型的高频摩擦音，频谱尖锐
- **th**：齿间摩擦，频率更低，能量分布不同
