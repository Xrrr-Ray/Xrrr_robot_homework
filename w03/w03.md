## 问题 1：机器人如何利用 OpenCV 识别并跟踪指定颜色的物体？

### 思路：

通过摄像头采集图像 → 转换为 HSV 色彩空间 → 用颜色阈值分割出目标区域 → 计算目标中心位置 → 控制机器人转向或移动。

### 解答：

**实现步骤：**

1. 读取摄像头画面；
2. 转换为 HSV；
3. 通过 `cv2.inRange()` 筛选目标颜色；
4. 计算轮廓中心（`cv2.moments`）；
5. 根据中心偏差控制机器人舵机或电机。

```python
import cv2
import numpy as np

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

    # 红色范围（可调整）
    lower_red = np.array([0, 120, 70])
    upper_red = np.array([10, 255, 255])
    mask = cv2.inRange(hsv, lower_red, upper_red)

    # 计算目标中心
    M = cv2.moments(mask)
    if M["m00"] > 0:
        cx = int(M["m10"]/M["m00"])
        cy = int(M["m01"]/M["m00"])
        cv2.circle(frame, (cx, cy), 10, (0,255,0), -1)
        # 控制逻辑：若cx偏左 -> 左转，偏右 -> 右转
    cv2.imshow("Tracking", frame)
    if cv2.waitKey(1) == 27: break

```

## 问题 3：如何让机器人通过 OpenCV 识别人脸并做出反应？

### 思路：

使用 OpenCV 自带的人脸检测（Haar 或 DNN），检测到人脸后控制机器人动作，如“打招呼”或“转头跟随”。

### 解答：

**代码示例：**

```python
face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')

while True:
    ret, frame = cap.read()
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, 1.3, 5)

    for (x, y, w, h) in faces:
        cv2.rectangle(frame, (x, y), (x+w, y+h), (255,0,0), 2)
        cx = x + w//2
        # 控制逻辑：若人脸偏右 -> 舵机右转一点
    cv2.imshow("Face Follow", frame)
    if cv2.waitKey(1) == 27: break
```
