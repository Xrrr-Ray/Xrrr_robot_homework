# 1. 为什么机器人需要融合多个传感器，而不是只用一个？

**回答：**
 单一传感器存在天然局限，比如：

- **激光雷达（LiDAR）**：距离精度高，但无法获取颜色、纹理信息，在强光或雨雾下性能变差。
- **摄像头（Camera）**：信息丰富，但对光照极其敏感，缺乏绝对尺度。
- **IMU**：短时间稳定、长时间漂移。

传感器融合（Sensor Fusion，例如 Kalman Filter、EKF、UKF）能带来：

1. **冗余**：一个传感器失效，其他还能补上。
2. **互补**：弥补彼此弱点，例如 LiDAR + IMU = 高精度定位。
3. **精度提升**：信息互校可增强环境感知。

所以机器人通常采用 **多传感器融合** 来实现可靠稳定的 SLAM、定位与避障。

# 2. 激光雷达扫描出来的点云为什么需要滤波和下采样？

**回答：**
 原始点云通常包含噪声、冗余数据，不利于实时计算，尤其像你的 **简化MPC + LiDAR 避障** 会受到很大影响。

常见原因：

- **噪声点**：反光、透明物体会产生错误距离。
- **过密点云**：毫无必要消耗大量计算资源（特别在嵌入式平台）。
- **离群点（Outliers）**：会导致错误的避障方向或地图畸形。

常见处理方法：

- **Voxel Grid 下采样**：把点云分为体素（voxel），每个用一个点代表。
- **Statistical Outlier Removal (SOR)**：去除离群点。
- **Radius Outlier Removal**：检测孤立点。

对于小车比赛来说，合理的点云预处理会让 MPC 或 PID 的避障响应更平稳。

# 3. 超声波传感器测距为什么会出现随机跳变？如何减少？

**回答：**
 超声波传感器（如 HC-SR04）常见跳变原因：

1. **多路径反射（multipath）**：声波在墙角、桌面多次反射后被接收。
2. **软材料吸声**：布料、毛毡会吸收声波导致距离不稳定。
3. **噪声和干扰**：同频的其他超声波设备或风扇会造成干扰。
4. **机械安装问题**：倾角过大导致波束偏离目标。
5. **温度影响**：声速随温度变化，影响精度。

减少跳变的方法：

- **平均滤波 / 中值滤波**：平滑随机跳变。
- **多次采样后取最可信值**（如取 3 次最小值）。
- **固定发射频率**，避免同频干扰。
- **合理安装角度**，保证目标在主波束范围内。
- **温度补偿**（或采用自带补偿的模块）。

在实际机器人控制中，超声波通常作为 **辅助传感器**，避免单独依赖。
